# OrangeHRM Manual Testing Project

This project contains manual test cases created while testing the OrangeHRM demo website.

## Project Overview
The goal of this project was to practice manual testing by identifying functional issues and documenting test cases.

- User Management
- Job Titles
- Corporate Branding
- Organization Locations
- Logout
